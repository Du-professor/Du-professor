## Featured projects / 精选项目

### [LLM Guard Agent](https://github.com/Du-professor/llm-guard-agent)

面向 OpenAI 兼容应用的本地安全网关，组合 Go 代理、Python/ONNX 分类、YAML 规则和 Docker 部署，检测越狱、提示词注入与内容风险。<br>
A local security gateway for OpenAI-compatible applications, combining a Go proxy, Python/ONNX classification, YAML rules, and Docker deployment to detect jailbreaks, prompt injection, and content risks.

`Go` `Python` `ONNX` `Docker` `LLM Security`

### [AI Skills Collection](https://github.com/Du-professor/AI-Skills-Collection)

可复用、可审查、可下载的 AI Skill 作品集，覆盖数据分析、商业洞察、技术决策、语言学习与防御性安全审计。<br>
A reusable, auditable, and downloadable collection of AI skills for data analysis, business insights, technical decisions, language learning, and defensive security auditing.

`AI Agents` `Prompt Engineering` `Documentation` `Automation`

### [ORB-SLAM3 Occupancy](https://github.com/Du-professor/ORB_SLAM3-OCCUPANCY)

围绕 ROS 2、RealSense、CUDA、OpenCV 与 ORB-SLAM3 的视觉 SLAM 和建图环境实践。<br>
A visual SLAM and mapping environment built around ROS 2, RealSense, CUDA, OpenCV, and ORB-SLAM3.

`ROS 2` `C++` `CUDA` `OpenCV` `ORB-SLAM3`
